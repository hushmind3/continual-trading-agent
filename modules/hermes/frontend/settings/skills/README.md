# 스킬

원본 스킬 목록과 내용을 읽습니다. 화면의 제목·분류는 한글로 표시하고 원본 지침은 접힌 상세 영역에 보존합니다. 한글 제목과 원본 식별자로 검색할 수 있습니다.

목록을 읽는 행위는 스킬을 실행하지 않습니다. 실제 모델이 스킬 도구로 필요한 지침을 읽으며, 일부 지침은 별도 프로그램이나 서비스 연결이 필요합니다.

검색 결과 개수·검색 초기화를 제공하고, 원문 읽기 실패는 무한 로딩 대신 오류·재시도를 표시합니다. 생성·편집은 공통 Drawer를 사용해 Escape·초점 복귀·키보드 이동을 공유합니다.

목록·선택은 Skills.tsx, 생성·편집 폼은 SkillEditor.tsx, 번역 이름·분류는 skillLabels.ts가 담당합니다. 스타일과 입력 요소는 공통 Tailwind/UI를 사용합니다.
