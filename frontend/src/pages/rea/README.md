# REA 분석·진단 화면

REAWorkspace.tsx는 REA 설치 버전·지원 Node·원본 MCP 도구 목록을 보여줍니다. 입력 스키마와 JSON을 확인하고 사용자가 실행을 요청합니다.

단일 API의 rea 상태 조회, rea/run, rea/doctor, rea/stop을 사용합니다. 원본 도구의 isError와 진단 결과를 그대로 표시하며 미지원 플랫폼·미설정 분석 엔진을 성공으로 표시하지 않습니다. MCP 대상/Evidence 문맥은 같은 서버의 다음 호출에도 유지됩니다.

원본 도구 검색·필수/선택 입력 양식·전체 JSON 전환·실행/중지·결과 본문을 제공합니다. 원본 입력 이름과 기본값을 유지하며 복합 객체·배열은 JSON으로 전달합니다. 양식에 없는 추가 입력은 JSON 모드에서 유지합니다. 자동 검사는 사용자 스크립트 실행 대상으로 미실행입니다.

목적별 JavaScript/Electron·네이티브 EXE/DLL·관리 코드 버튼은 원본 도구를 선택합니다. 네이티브 열기는 Ghidra를 명시 선택합니다. 엔진 경로 저장·원본 엔진별 준비 확인은 사용자 클릭 때만 실행합니다. 원본 parent_evidence_id로 같은 세션의 요약·sections/symbols/modules 페이지 조회 입력을 구성하며 실제 조회는 실행 버튼으로 요청합니다. 모든 원본 도구/JSON 입력은 유지합니다.
