# 헤르메스

대화가 전체 작업 영역을 사용합니다. 상단에는 대화/설정만 있으며 settings/ 아래 models/, mcp/, skills/를 모았습니다. 설정을 열어도 Chat은 유지되어 작성 중인 메시지와 선택 세션이 사라지지 않습니다.

chat/Chat.tsx는 접이식 세션 목록, 대화 전송·중지·자율 실행·실시간 세션 갱신을 담당합니다. chat/ChatStream.tsx는 도구 호출과 결과를 한 줄로 묶고, 선택한 작업 내역 패널 및 실제 엔진 수치를 표시합니다. Workspace.css는 이 페이지에만 적용하는 전체 높이 레이아웃입니다.

상태 조회는 첫 진입과 화면 복귀, 작업/모델 로딩 중에만 실행합니다. 상태 조회 자체가 모델이나 외부 도구를 실행하지 않습니다. 대화 갱신은 작업 중에만 수행하며 사용자가 위로 스크롤했으면 위치를 강제로 내리지 않습니다.

컨텍스트와 입력/출력은 엔진 보고 값이며 생성 속도는 소유한 llama.cpp 슬롯의 생성 토큰 증가량/측정 간격입니다. 수치가 없으면 대기/미확인으로 표시하며 문자 수를 토큰으로 바꾸어 표시하지 않습니다. 생성 속도는 최근 측정 구간 값입니다.
