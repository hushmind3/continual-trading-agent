# 공식 기능의 플랫폼 화면

용도: 공식 React 기능을 기존 헤르메스 설정 탭과 공통 디자인으로 제공합니다.

- 기능 탐색은 가로 스크롤 탭과 이전·다음 버튼을 사용합니다. 프로필 변경은 페이지를 새로 연결하고, 플러그인의 기본 기능 대체 경로를 유지합니다. 없는 경로는 설정 복귀 안내를 표시합니다.
- OfficialWorkspace.tsx: 원본 페이지·프로필·플러그인·한국어 문맥.
- 명령 실행은 원본 ChatPage·PTY를 제공해 공식 CLI 명령을 사용할 수 있습니다. resume 식별자로 기존 대화를 이어갈 수 있으며 기본 대화 열기는 기존 플랫폼 대화를 유지합니다.
- ResumeSession.tsx: 기본 프로필의 대화 기록을 기존 플랫폼 대화로 이어갑니다.
- transport.ts: Request 객체의 메서드·헤더·본문을 보존하며 외부 WebSocket 주소는 변경하지 않습니다.
- transport.ts: 실제 공식 HTTP·파일·WebSocket을 같은 /api/ai_agent/Hermes/native/에 연결합니다.
- frontend/official-vite.ts: 원본 모듈 경로·전송·공통 스타일 경계를 연결하고 버전 관리된 한글 패치를 준비합니다.
- 디자인·글꼴은 frontend/src/tailwind.css를 공유합니다. 기존 주 대화와 사업·직원·회의 기능을 유지합니다.
- backend/native/ → 기존 worker → 공식 ASGI 앱. 기존 runtime/ai_agent/Hermes를 사용합니다.
- 2026-10-26: 실제 모델·스킬·업무 보드 화면, WebSocket 연결 승인, Pretendard 공통 글꼴·흰색 배경·가로 넘침 없음·화면 오류 0건 확인. 타입 검사·Vite 빌드 통과. 외부 인증이 필요한 전체 기능의 실제 실행은 미확인입니다.

추가 확인: 내장 관리 화면·설치 플러그인 포함 메뉴 20개 등록, 명령 화면의 실제 PTY·RPC·이벤트 메시지와 보조 패널 정상 연결을 확인했습니다. 공식 명령 화면의 브라우저 토큰 사전 검사와 내부 클라이언트의 접속 주소도 플랫폼 인증·동일 게이트웨이 경로에 맞췄습니다. 원본 비공개 자격은 브라우저로 넘기지 않습니다. 명령 화면은 다른 관리 화면을 볼 때도 원본처럼 유지하고 프로필의 초기 동기화만으로 재생성하지 않습니다. 마지막 기능 위치는 세션 저장소에서 복원하며, 같은 기능 안의 이동을 상위 탭이 강제로 되돌리지 않습니다.

폰트·표제·입력·버튼·가로 탐색은 공통 tailwind.css를 사용합니다. 실제 390px 화면에서 가로 넘침 없음(기능 탭만 내부 스크롤), 1440px 화면에서 원본 도구·모델 페이지와 오류 없는 렌더링을 확인했습니다. 공식 디자인 시스템과 라우터는 npm의 실제 의존성 해석을 사용해 워크스페이스 배치가 바뀌어도 고정 node_modules 위치에 의존하지 않습니다.

원본 대화상자의 createPortal 대상은 transport.officialPortalRoot의 공통 테마 범위입니다. 본문 밖으로 나가며 글꼴·배경을 잃는 문제를 방지하고, 원본 버튼·확인·초점 처리와 외부 WebSocket은 보존합니다. openOfficial의 이동 이벤트는 이미 열린 공식 작업공간에도 적용합니다.

모델 선택기의 실제 배경·Pretendard 글꼴·닫기/변경 버튼·390px 단일 열 배치를 기존 서버에서 확인했습니다. 원본 기능 호출은 유지하고 모델 선택창 내부 레이아웃에만 공통 Tailwind 스타일을 적용합니다.
