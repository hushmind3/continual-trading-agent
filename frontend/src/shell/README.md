# 메뉴·화면 구역

| 파일 | 역할 |
| --- | --- |
| Shell.tsx | 메뉴 정의·기존 URL 해석·지연 로딩·구역 표시·오류 관련 화면 연결 |

- FinRL · 메인, FinRL-Trading · 보조, 거래 운영, 프로젝트 확장, 연결·관리 구역을 구분합니다.
- 오류는 실제 module_errors 항목으로 표시합니다. 프레임워크 접두사와 조회 항목의 담당 구역을 사용하며 알 수 없는 항목은 공통 진단으로 연결합니다.
- 구역별 오류 수는 응답에 포함된 오류 항목 수입니다. 실제 근본 원인을 확정하는 판정이 아닙니다.
- 메뉴의 component 경로는 pages/의 실제 기능 폴더와 일치해야 합니다.
- App.tsx에 개별 화면 import나 API 호출을 추가하지 않습니다.

## 큰 메뉴별 등록

menu_groups/menu_registry.ts는 큰 메뉴별 연결 파일 5개만 import합니다. Shell.tsx는 등록표만 읽습니다. 각 연결 파일의 이름에 구역 이름을 넣어 동일한 entry 파일명을 사용하지 않습니다.

백엔드의 menu_catalog에서 등록된 추가 기능을 읽어 해당 큰 메뉴 아래 자동 표시합니다. 작은 메뉴 15개를 연결하고 별도 등록 작업은 독립 메뉴로 제공합니다. 백엔드 기능 전체 화면에서 큰 메뉴·작은 메뉴·원본 함수·API·입력값을 확인할 수 있습니다.

추가 기능도 큰 메뉴 매니저가 등록하며 Shell.tsx에 기능 등록 코드를 누적하지 않습니다.

현재 화면에는 같은 큰 메뉴 구역의 모듈 오류를 표시합니다. Champion 오류는 프로젝트 확장 구역에 연결됩니다. 다른 구역 오류 수와 공통 진단 링크를 유지하고 공통 진단 화면에서는 전체 오류를 표시합니다. API 연결 오류는 전역 표시입니다. 실제 로컬 브라우저 검사는 38개 등록 화면과 구역별 오류·공통 진단을 확인합니다.
