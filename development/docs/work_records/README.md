# 이전 작업 기록

프로젝트 외부 Windows Temp에 남아 있던 이 프로젝트 전용 작업 스크립트·의존성 버전표·정리 조사 결과를 이 폴더로 옮겼습니다. 원래 경로는 relocated_files.json에 기록되어 있습니다.

- *.py: 이미 완료한 폴더 이동·메뉴 통합·npm 통합·정리 작업의 일회성 기록입니다. 현재 상태에 재실행하는 설치·검사 스크립트가 아닙니다.
- npm_original_versions.json: npm 통합 전 버전 비교 기준입니다.
- platform_cleanup_*.json: 이전 정리 조사·이동 결과입니다.
- previous_frameworks_README.md: 금융 화면을 소속 메뉴로 옮기기 전 폴더 안내입니다.

플랫폼은 이 폴더를 import·실행·빌드에 연결하지 않습니다. 실제 실행 코드는 backend/·frontend/에, 사용자가 실행하는 설치·서버 스크립트는 scripts/에 있습니다. Codex 자체 플러그인·일반 임시 파일·다른 프로젝트 파일은 이 프로젝트의 구성물이 아닙니다.

완료된 일회성 Python 이동·정리 스크립트 8개는 재실행할 용도가 없어 휴지통으로 옮겼습니다. 현재 이 폴더에는 JSON 조사 결과와 당시 README만 보관합니다.
