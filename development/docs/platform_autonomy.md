## 완료한 수정
- MoE: 입력 계약이 없는 등록 항목 및 손상된 브라우저 저장값 때문에 화면이 비는 문제 수정(2838906).
- REA: 저장 경로 생성 실패 후 분석 잠금이 남는 오류 수정. 불완전한 프로젝트 기록 때문에 전체 목록이 깨지는 오류 수정.
- REA: 추출 폴더에서 프로젝트 휴지통 제외. 파일 선택을 빠르게 바꿀 때 늦은 이전 응답이 현재 미리보기를 덮는 문제 방지.
- 서버 시작: 기존 서버켜기.cmd와 바탕화면 바로가기를 같은 진입점으로 연결. 서버 시작이 금융 전체 시스템 시작을 호출하지 않도록 분리. 추가 설치 없음.

## 금융 요청 검사·수정 (2026-10-14)
- 수정 전 임시 계좌에서 0 가격은 ZeroDivisionError, 누락 가격은 TypeError, NaT 시각은 실제 가상체결 수락을 재현. 수정 후 잘못된 시세·호가를 ValueError/HTTP 400으로 거부하고 계좌가 그대로인지 확인.
- 수량 true가 1로 처리되던 문제 수정. bool/소수/문자열/0/음수를 HTTP 422로 거부하고 실행기를 호출하지 않음. 정상 정수 주문은 기존 계산 규칙으로 임시 매수·매도 성공.
- UI 소수 수량 주문 버튼 차단 및 입력 오류의 필드·사유 표시. 인증 등 제출 값 자체는 오류 문구에 노출하지 않음.
- 잘못된 운영 통화 자료형이 서버 500을 만들던 문제 수정. 정상 USD/KRW 목록·중복 제거 동작 유지. 실제 system/start 대신 가짜 실행기를 사용.
- 잘못된 종목 목록·장치 값이 설정에 저장되던 문제 수정. 실패 시 기존 임시 설정 파일 바이트가 그대로인지 확인. 실제 로컬 설정은 변경하지 않음.
