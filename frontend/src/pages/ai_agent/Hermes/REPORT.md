# Hermes 화면 개선 — 2026-10-16

## 적용 결과

- 중복 상단 영역을 하나의 대화 헤더로 합쳤습니다. 기본 화면은 플랫폼 메뉴를 유지하고, 집중 모드는 화면 전체를 사용합니다.
- 본문 글자 크기는 데스크톱 16px, 모바일 15px입니다. 입력창은 16px이며 내용에 맞춰 최대 160px까지 늘어납니다.
- 답변의 제목·목록·표·코드를 서식대로 표시하고 답변/코드 복사를 제공합니다. 연속 도구 호출은 하나의 작업 기록으로 묶고, 실제 결과와 오류를 보존합니다.
- 세션 검색, 세션별 초안 저장, 최신 메시지 이동, 접이식 작업 내역, 모바일 배경 닫기·Escape·포커스 복귀를 추가했습니다.
- 모델·MCP·스킬 설정은 데스크톱 설명형 메뉴와 모바일 탭으로 정리했습니다. 설정을 다녀와도 대화와 초안이 유지됩니다.

## 검사와 실행의 구분

- TypeScript 검사와 프로덕션 빌드 통과.
- `frontend/tests/hermes-workspace.local-browser.spec.ts` 4개 검사 통과. Markdown/표/코드/실행 타임라인, 복사, 초안, 세션 검색, 반응형, 키보드, 목표 실행·중지·질문 응답의 API 요청 형식을 검사합니다.
- UI 검사는 Hermes API를 픽스처로 대체합니다. 실제 추론이나 도구 실행 성공을 의미하지 않습니다.
- 실제 서버에서는 화면·설정 목록·새 빈 대화 생성·모델 준비 상태를 확인했습니다. 검증용 빈 대화는 보관 처리했습니다. 관찰한 페이지 오류는 0건입니다.
- 금융 운영 화면의 기존 헤더와 여백도 확인했습니다. 금융 기능 전체의 실행 검증은 이번 범위가 아닙니다.
- Markdown 라이브러리 두 개를 공통 npm 환경에 추가했고 기존 패키지 버전 변경은 없었습니다.
