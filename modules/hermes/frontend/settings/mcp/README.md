# 외부 도구

용도: 이식 Hermes의 MCP 연결·카탈로그 화면과 원본 설명의 한국어 표시 범위를 안내합니다.

MCP 서버를 프로그램 실행 방식 또는 서버 주소 방식으로 추가합니다. 저장은 설정만 바꾸며, 연결하기를 눌러 원본 Hermes의 MCP 검색·연결을 실행합니다. 기존 환경 변수와 인증 헤더 등 추가 필드는 보존하며 고급 설정에서 편집할 수 있습니다.

파일·명령 실행은 내장 도구여서 MCP 연결이 필수는 아닙니다. 연결 설정 삭제는 서버 프로그램 파일을 삭제하지 않습니다. 상태는 실제 연결 여부와 도구 수를 표시하고 원본 진단 정보는 펼쳐 볼 수 있습니다.

기본 제공 기능과 추가 MCP 서버를 분리해 표시합니다. MCP 설정 파일의 mcpServers / mcp_servers / servers 래퍼 또는 직접 서버 맵을 가져올 수 있습니다. 수정 시 환경 변수·인증 헤더 등 부가 필드를 보존합니다. 연결 실패를 정상 연결로 표시하지 않으며 실제 도구 수를 사용합니다.

카탈로그/내 연결은 공통 Tabs를 사용합니다. 탭 변경 때 방문한 연결 화면을 숨겨 유지해 작성 중인 설정을 잃지 않습니다. 설치 입력창은 공통 Drawer로 Escape·초점 복귀를 지원합니다.

`McpCatalog.tsx`는 설치·연결 동작을 담당하고, `catalogInstructions.ts`는 카탈로그의 원본 설치 안내와 인증 입력 도움말을 한국어로 표시합니다. 원본 manifest, 실제 서버 주소·실행 명령·환경 변수 이름과 인증 흐름은 바꾸지 않습니다. 카탈로그 요약은 `../../catalogLabels.ts`에서 관리합니다. 실제 화면은 플랫폼 8766의 헤르메스 설정 → 외부 도구 → 카탈로그에서 설명을 펼쳐 확인합니다.
