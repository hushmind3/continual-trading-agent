# 키움 실시간 입력·원화 및 달러 학습 화면

- 실시간 공급원은 키움으로 고정했습니다. 저장된 예전 Yahoo 선택값은 실행 시 키움으로 처리하며, 인증·계좌·키 발급 환경 파일은 덮어쓰지 않았습니다. 설정이 없는 경우에는 실전 시세 환경을 기본으로 표시합니다.
- 가상매매 live 입력에서는 Yahoo 분봉 수집을 호출하지 않습니다. 기존 키움 이벤트 수신·완료 바 저장 경로는 유지합니다. 과거 학습 자료의 Yahoo 일봉·FMP·WRDS는 실시간 공급원과 구분합니다.
- 공개 시세 선택 버튼·provider/public API와 Alpaca 연결 표시를 제거했습니다. 키움 접속이 없을 때 다른 실시간 공급원으로 전환하지 않습니다. 미국 시세는 기존 SDK에서 실전 키 환경을 요구합니다.
- 정책 학습은 원화·달러 카드를 동시에 표시합니다. 종목 선택·전체 종목 표·USD 단일 기본 선택을 제거하고, 해당 통화에 등록된 학습 대상 전체를 요청 본문에 명시합니다. 현재 등록 대상은 KRW 105개·USD 89개입니다. 가격이 없는 종목을 자동 제외하거나 기존 Champion 종목으로 덮어쓰지 않습니다.
- 선택한 알고리즘의 FinRL MODEL_KWARGS와 실제 설치된 SB3 생성자 기본값을 표시합니다. 7개 알고리즘의 설정값을 API에서 확인했으며 공식 알고리즘·학습 기본값·환경 규칙은 변경하지 않았습니다.
- 가상계좌는 원화·달러를 동시에 표시합니다. 기존 계좌·모델·Replay·가격 자료는 변경하지 않았습니다.
- MoE 생성 버튼도 원화·달러를 명시적으로 구분하고 등록 종목을 전달합니다. 폐기한 정책 학습 통화·종목 sessionStorage를 재사용하지 않습니다. 생성·학습·주문은 사용자가 버튼을 눌렀을 때만 실행합니다.
- 사용처가 없어진 SAC 전용 구조 및 단일 모델 준비 화면 2개는 휴지통으로 옮겼습니다.

실제 확인: Vite 빌드·서버 적용 성공. 읽기 API에서 provider=kiwoom, 환경=real, 저장 인증 있음, KRW·USD 모델 상태, 7개 알고리즘 기본값 응답 및 조회 오류 없음 확인. 실제 접속 토큰 발급·시세 수신·정책 생성·학습·추론·가상체결·브라우저·타입 검사는 실행하지 않았습니다. 저장 인증 있음은 실제 접속 성공을 뜻하지 않습니다.
