# 개발 자료

용도: 개발·설치·검사 자료의 위치와 운영 코드와의 경계를 안내합니다.

- scripts/: 설치·서버 적용·사용자가 실행하는 모듈 참조 조사와 requirements/.
- tests/: 사용자가 실행하는 Python 검사 소스.
- docs/: 구조·설정·사용 조사·정리 보고서.

공통 호스트는 루트 backend/·frontend/, 실제 업무 소스·패키지·설정은 modules/<id>/에 있습니다. 루트 서버켜기.cmd와 설치.cmd가 scripts/의 해당 진입점을 호출합니다. 이 폴더의 문서·검사·작업 기록은 플랫폼 기능으로 등록하지 않습니다.

현재 실행 명령은 [scripts 안내](scripts/README.md), 모듈 소유·완료 범위는 [모듈 안내](../modules/README.md)를 따릅니다. docs/의 조사·검사 보고서는 작성 당시 조건의 기록이며 현재 구현의 기준 문서를 대신하지 않습니다.
