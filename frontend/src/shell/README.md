# 공통 메뉴와 화면

- `Shell.tsx`: 상단 바, 금융·REA·AI 에이전트 메뉴, 현재 화면 제목, 갱신 시각, 오류와 알림 창.
- `menu_groups/menu_registry.ts`: 금융·REA·AI 에이전트 매니저를 취합합니다. 새 기능은 소속 매니저에서 등록합니다.
- 기본 화면 7개: 운영 제어, 가상계좌·주문, 정책 학습, MoE, 연결·설정, 프로그램 분석, 프로젝트 탐색. 백엔드 등록 작업은 등록표에 따라 추가될 수 있습니다.
- `Page`는 등록된 컴포넌트를 지연 로딩하며 필요한 상태가 없으면 오류를 표시합니다. 금융 작업을 자동 시작하지 않습니다.
- `errorSection`은 응답의 모듈 오류를 관련 사용자 화면으로 연결합니다. 오류 개수는 원인 개수가 아닙니다. 개발자용 진단·백엔드 기능 전체는 기본 메뉴에 표시하지 않습니다.
- 데스크톱은 전체/아이콘 메뉴, 모바일은 같은 메뉴를 공통 Drawer로 표시합니다. 알림 창은 오류·작업 정보를 표시합니다.
- 메뉴 이동 시 맨 위로 스크롤하고 본문으로 키보드 초점을 옮깁니다. 처음 진입할 때는 임의로 초점을 옮기지 않습니다. 브라우저 탭 제목은 `현재 화면 · 프로젝트 플랫폼`입니다.
- 공통 `ui/Primitives.tsx`의 Drawer는 Escape 종료·열기 버튼 초점 복귀·Tab/Shift+Tab 순환을 제공합니다. 숨겨진 입력과 비활성 입력은 제외하고 textarea를 포함합니다. 배경 닫기 버튼은 Tab 순서에서 제외합니다.
